对于 KP-9000-6XH-X2 / KP-9000-6XHML-X2 / Mokerlink 2G040210GSM 设备，需要根据 PCB 版本来选择 machine target。
仅凭 ML/非 ML 或网管/非网管的标签无法确定接线方式。

其他基于 RTL8272/3 且可能可以工作的设备在这里有描述：[Up-N-Atoms 2.5 GBit RTL Switch hacking guide](https://github.com/up-n-atom/SWTG118AS)

许多 RTL8272/3 设备有支持 PoE 的版本。RTLPlayground 通常也能在这些设备上工作，但没有提供配置 PoE 的支持，原因很简单：这些设备通常只是在所有端口上直接提供 PoE，没有更多的配置可能性。

以下论坛也在讨论这类交换机：[ServeTheHome](https://forums.servethehome.com/index.php?threads/horaco-2-5gbe-managed-switch-8-x-2-5gbe-1-10gb-sfp.41571/)

也有采用 RTL8272 SoC 的 16 端口非网管型设备，但这些设备没有串口控制台，并且使用 4 颗独立的 RTL8272 SoC。即使已经有人成功演示过将 RTLPlayground 安装到单个 SoC 上，RTLPlayground 也不提供集中控制。

- [Vimin VM S251602P 16 Port 2.5G PoE Switch With 2x 10G SFP+](https://www.servethehome.com/vimin-vm-s251602p-16-port-2-5g-poe-switch-review-cyperf/vimin-vm-s251602p-16-port-2-5g-poe-switch-with-2x-10g-sfp-battery-2/)
