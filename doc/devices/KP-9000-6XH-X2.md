# Keeplink KP-9000-6XH-X2 / KP-9000-6XHML-X2

[English](KP-9000-6XH-X2.en.md) | 简体中文

以下是丝印为 `KP-9000-6XH-X2` 或
`KP-9000-6XHML-X2` 的交换机的文档。

使用 SPI 夹具夹住板载 Flash 颗粒是初次安装的唯一方法。

### 标签规格

- **名称**:4 个 2.5G RJ45 端口 + 2 个 10G SFP+ 端口  
- **型号**:KP-9000-6XH-X2 / KP-9000-6XHML-X2
- **端口**:  
  - 4 × RJ45:10/100/1000/2500 Mbps  
  - 2 × SFP+:1000 / 2500 / 10000 Mbps  

### 机型目标

这些设备存在不同的 PCB 版本。请根据 PCB 丝印而非外壳上的标签来选择机型目标。
`6XH` / `6XHML` 的区别看起来只是原厂固件、SKU 或标签上的差异,并不能可靠反映 PCB 布线。
PCB 版本决定了硬件布局。

| PCB 丝印 | 已知标签/设备 | 推荐机型目标 | 等效目标 | 旧版目标 |
| --- | --- | --- | --- | --- |
| `2M-PCB43-V1.1` | Mokerlink 2G040210GSM 支持 Web 管理的 4+2 口交换机 | `MACHINE_KP_9000_6XHML_X2_V1_1` | `MACHINE_KP_9000_6XH_X2_V1_1` | `MACHINE_KP_9000_6XHML_X2` |
| `2M-PCB43-V1.2` | `KP-9000-6XHML-X2` | `MACHINE_KP_9000_6XHML_X2_V1_2` | `MACHINE_KP_9000_6XH_X2_V1_2` | `MACHINE_KP_9000_6XHML_X2` |
| `2M-PCB43-V2.1` | `KP-9000-6XH-X2`、`KP-9000-6XHML-X2` | `MACHINE_KP_9000_6XH_X2_V2_1` 或 `MACHINE_KP_9000_6XHML_X2_V2_1` | 相同的 V2.1 布局 | `MACHINE_KP_9000_6XH_X2` |

V1.1 和 V1.2 板卡目前使用相同的 V1.x GPIO、SFP、端口和 LED 布局。
V2.1 板卡使用不同的 V2.1 布局,带有自定义的 LED 复用。
保留旧版目标是为了兼容已经测试过的设备,但新的构建应优先使用明确对应 PCB 版本的目标。

### 已实现的功能

- 全部 4 个 2.5GBASE-T RJ45 端口,支持 10/100/1000/2500 Mbps
- SFP 端口,支持 10G 模块 
- LED 灯
- 因缺少硬件未测试:搭载 1G 或 2.5G SFP 模块的 SFP+ 端口。

## 重置按键

PCB 前部左侧有一个未焊接的重置(Reset)按键。
它很容易焊接,你需要一颗 4.5mmx4.5mm 的 90° 按键开关,带 3 引脚焊盘。
我的是在这里买的:https://de.aliexpress.com/item/1005007295346702.html
前面板的金属外壳上已经开好了孔,你只需把覆膜捅穿即可。

## 供电

电源输入通过圆形插头(barell plug)提供,附带 `12V 1A` 适配器。
