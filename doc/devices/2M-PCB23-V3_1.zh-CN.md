注意:元件编号规则为 `<L>-<REFDES>-<SIDE>`
* L:层(Layer),T=顶面(Top),B=底面(Bottom)
* REFDES:完整丝印编号,如 `R123`
* SIDE:元件所在的一侧。当 RJ45 面朝你、丝印可以正常读出时:
  L = 左(Left),R = 右(right),B = 下(bottom),T = 上(top),或者是带针脚编号的 P。

### T7,从机接口(Slave Interface)
|`T7` 针脚|说明|信号|元件|
|---|---|---|---|
| 1 | 从机接口 | Slave SCK/SCL/MDC/EE_SCL | U7-6 |
| 2 | GND   | | |
| 3 | 从机接口 | Slave SDI/SDA/MDIO/EE_SDA | U7-5 |
| 4 | 3V3   | | |
| 5 | GPIO? | | |
| 6 | GPIO? | | |

`U7` 可以是一片标准 I2C EEPROM 存储器,例如 `24LC32`。

从机接口允许外部主机控制 SoC,即使内部 MCU 正在使用中也是如此。
根据 `IF_SEL` 启动配置电阻的不同,该接口可以是 `I2C`、`SPI` 或 `SMI`。
在本设备上为 `I2C`,地址为 `0b1011100` 或 `0x5c`(7 位表示法)。

* I2C 读:必须是一次 write_read 操作:`<Dev-ADDR><RegAddr15:8><RegAddr7:0>` `<DevAddr><Data7:0><Data15:8><Data23:16><Data31:24>`。
* I2C 写:`<Dev-ADDR><RegAddr15:8><RegAddr7:0><DevAddr><Data7:0><Data15:8><Data23:16><Data31:24>`。

例如寄存器 `0x0004` 返回芯片 ID `0x00, 0x00, 0x72, 0x83` = `0x83720000`。

# 供电

板上有两条供电轨。
`0.95` 和 `3.3` 伏。

## `0.95` 核心电压

该电压由 `MP2225GJ` Buck(降压)转换器产生。
0.95V 必须在 3% 以内。

## `3.3` 电压

该电压由 `MP2225GJ` Buck(降压)转换器产生。
3.3V 必须在 4.5% 以内。
该芯片最大可输出 5A,最佳工作点为 2A。
因此大功率 SFP 模块应该也能工作。


[^1]: 这些 LED 的查找方法很简单:插上一个 RJ45 接头,然后用 `gpio` 命令观察状态变化。但端口 1、2 的位模式与端口 3、4 不同。
