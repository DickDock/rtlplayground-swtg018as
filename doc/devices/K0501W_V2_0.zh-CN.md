# K0501W V2.0

[English](K0501W_V2_0.md) | 简体中文

该板卡例如出现在 Davuaz Da-K6501W 交换机中。

该板卡的整体设计与 Hi-K0402WS V3.0 类似。
但存在以下几点不同:
- 一个 SFP 端口被一颗 RTL8221B 2.5G PHY 取代
- SFP 端口只焊接了一颗 LED 灯
- 没有模式切换开关,且只有一颗 Flash 颗粒
- 采用较早的设计,使用 RTL8372 而非 RTL8372N(这也意味着不同的 GPIO 和 LED 配置)
- 与 K0402W(S) 板卡的早期版本一样,没有 UART

所有端口和 LED 灯均受支持。
可以使用编程器进行安装。
BoyaMicro 25Q16BSSIG Flash 颗粒受 flashprog 支持,芯片名称为“B.25D16AS/BY25Q16BS/BY25Q16ES”。
